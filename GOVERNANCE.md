# Project governance

BRAD is presently maintained by the repository owner, **[@niamatmarjan](https://github.com/niamatmarjan)**. It has not formed a foundation, advisory board, or multi-maintainer steering committee.

## Decision process

- Anyone may propose or review changes through GitHub issues and pull requests.
- Maintainers review security, scope, native BMAD compatibility, licensing/provenance, and regression evidence before merge.
- Changes to BRAD's public contract, required permissions, or compatibility may need extended discussion and a minor version bump.
- Maintainers choose release timing after checks pass. No contributor text can authorize unreviewed publish/merge/deploy.
- Disagreements should be resolved through specific evidence and respectful discussion under the [Code of Conduct](CODE_OF_CONDUCT.md).

## Releases and stewardship

Release process: [docs/releasing.md](docs/releasing.md). Security handling: [SECURITY.md](SECURITY.md). Ownership or maintainership may evolve transparently in future changes; current GitHub collaboration permissions remain authoritative.
