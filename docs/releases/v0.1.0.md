## BRAD v0.1.0 — Initial open-source preview

**Just ask BRAD.** A thin BMAD Method workflow wrapper derived from the BMAD Auto v3 prototype.

### Highlights
- Single entry point for tickets, QA/TEA, research, architecture, epics and sprint workflows.
- Ticket-to-PR delivery contract with explicit Git publishing authorization and no automatic merge.
- Source-of-truth routing for installed BMAD v6 and v7-preview interfaces.
- Safe clarification, preflight, recovery and evidence-based reporting rules.
- Full set of 85 routing scenarios, 14 baseline structural/helper tests and open-source developer documentation.

### Status
Preview for supervised evaluation. The scenario suite has not yet been verified against real subagents in every supported host, and the v7 surface remains version-dependent.
