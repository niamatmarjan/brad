# BRAD v0.5.0 — Cross-platform regression hardening and native-discovery evidence

## Improvements
- npm pack test supports observed array and name-keyed JSON formats with strict identity/file validation.
- Windows junction and POSIX symlink regression coverage tests install/update/uninstall and parent redirects without lowering OS security.
- CLI doctor reports project-local skill inventory separately from host/native execution verification.
- Host guidance explicitly differentiates cache, installation, discovery, execution and delivered outcome.
- GitHub CI covers Node 20/22/24 and Windows Node 22/24.

## Boundaries
These changes are an engineering test/diagnostics improvement, not proof of live BMAD specialist execution or successful multi-agent orchestration.
The v0.4.1 Concourse evaluation remains PARTIAL. BRAD remains a supervised preview, not production-certified.
