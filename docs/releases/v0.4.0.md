# BRAD v0.4.0 — Routing evidence and safer diagnostics

This supervised-preview release responds to issues flagged by the October 2026 Antigravity validation dossier.

- Adds `audit_routing_results.py`, a read-only evaluator for actual observed routes against the 85 canonical scenarios.
- Ships a selected set of **reported** routing mismatches as regression fixtures, not execution proofs.
- Adds `routing-verification.md` to favor correct BMM, PO, QA/TEA and code-review specialists over unrelated help/Build fallbacks.
- Enhances Git/GitHub and npm environment remediation without global policy changes or automatic remote writes.
- Adds explicit machine-readable readiness levels to `brad doctor`.

## Install

```bash
npx --yes "github:niamatmarjan/brad#v0.4.0" setup
npx --yes "github:niamatmarjan/brad#v0.4.0" doctor --json
```

Windows PowerShell may require `npx.cmd`. Native BMAD installation remains separate and needs consent.

## Verification boundary

Installer and script tests do not certify real BMAD subagent calls, GitHub PRs or v7 behavior. Review raw lab logs before drawing production conclusions.
