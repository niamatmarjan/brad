# BRAD v0.2.0 — Simple npx installation

This preview adds a safe zero-dependency Node.js CLI to the complete BMAD Auto v3-derived BRAD skill.

## New in this release

- Install BRAD from the tagged GitHub source with `npx --yes github:niamatmarjan/brad#v0.2.0 init` (Node.js 20+).
- Target Antigravity, Codex, Claude Code, or GitHub Copilot; use `--agent ...` to choose explicitly.
- Diagnose an installation using `doctor`, reinstall cleanly with `update`, and remove installed files using `uninstall`.
- Safe idempotent defaults, conflict detection, backups for forced overrides, dry-run and JSON output.
- Automated CLI and installer tests, npm tarball build, CI checks on Node.js 20/22.

**Compatibility:** BRAD remains a preview. Installer correctness is validated locally and in CI, not the underlying BMAD v6/v7 live multi-agent execution. BMAD itself must be installed separately.

**No npm registry publication:** Use the tagged GitHub npx command; the package is not yet available as `npx @niamatmarjan/brad`.
