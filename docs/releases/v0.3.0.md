## BRAD v0.3.0 — AI-first installation and clearer diagnostics

- New `brad setup` command for an agent-led quick start (safe, idempotent installation of BRAD, **not** automatic BMAD installation).
- New `brad prompt` command produces a project-specific instruction for a coding assistant; supports `--json`.
- Canonical `docs/AI_SETUP.md` for Antigravity, Claude Code, Codex, and GitHub Copilot, plus a repo `AGENTS.md` for contributor agents.
- `doctor --json` now distinguishes local BMAD runtime/skill hints from configured native BMAD, provides actionable next steps and Windows command tips.
- Expanded CLI and repository contract tests, Windows-specific diagnostics, explicit release verification boundaries and validation-lab learnings.
- All changes are setup and documentation focused; native BMAD workflow routing remains delegated to installed BMAD skills. No changes to production code or external service permissions.

**Maturity:** Public preview / supervised pilot. No npm-registry publication is implied; install via GitHub-tagged `npx` command.
