# BRAD v0.5.1 — Safer routing, actionable diagnostics and truthful execution evidence

BRAD v0.5.1 is a small, supervised-preview maintenance release. It retains BRAD's thin-router design and does **not** replace native BMAD Method workflows.

## Improvements
- `brad doctor --json` provides consent-gated recovery guidance that distinguishes a missing BMAD installation from partial configuration, missing project-local skills, and host catalog verification. The doctor remains read-only and does not prove invocation.
- Increment-aware PRD routing preserves existing approved requirements, stable identifiers and established backlog ownership instead of regenerating the full PRD.
- Review-only requests explicitly prohibit implementation, commits, branches, PR publication and other writes without separate authorization.
- Host handoff instructions distinguish actual host-native invocation, same-session inline native workflow execution, independent specialist subagents and helper-scripts-only activity. Passing tests and generated files cannot by themselves prove how a skill was invoked.
- Regression coverage for doctor recovery and routing safety, with Node.js 20/22/24, Windows Node.js 22/24, and Python 3.11/3.12 CI.
- Documentation reorganized into maintained topic guides with compatibility links for older documentation paths.

## Installation
From your project root (Node.js 20+):

```sh
npx --yes "github:niamatmarjan/brad#v0.5.1" setup
```

BRAD does not install native BMAD Method automatically. Existing projects should keep their configured BMAD version unless the owner approves a change.

## Validation boundaries
- This release improves local diagnostics and workflow safety contracts; it is **not** proof of 85/85 behavioral routing accuracy, universal host-native BMAD/TEA dispatch, independent agents on every host, or unattended ticket-to-PR delivery.
- The separate RelayDesk evaluation demonstrated a bounded inline BMAD Build / independent-subagent review and QA fixture, but has unverified host-native dispatch and remains separate from the release branch.
- BRAD remains a **supervised preview**, not production-certified. Never equate `HELPER_SCRIPTS_ONLY` or `NATIVE_WORKFLOW_INLINE` with `HOST_NATIVE_INVOKED`.
