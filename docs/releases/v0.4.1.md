# BRAD v0.4.1 — Open-source readiness and demo-preparation patch

This patch improves the open-source repository and distribution hygiene following v0.4.0, with **no new claim of production autonomy**.

- Expanded MIT copyright/attribution explanation and separate, non-restrictive branding guidance.
- CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, SUPPORT, GOVERNANCE, ROADMAP and repo-level templates.
- Release checksums, packaging validation, Windows/PowerShell smoke tests, and reproducibility checks.
- Future-demo acceptance and privacy rules; a copyable GPT‑6.1 Sol validation plan for 7 independent agent tracks and one self-contained master HTML evidence report.

## Assets

- `brad-v0.4.1.zip` — portable BRAD skill and necessary legal/setup files.
- `niamatmarjan-brad-0.4.1.tgz` — GitHub-backed npx installer package.
- `SHA256SUMS.txt` — release artifact checksums.

**Install** (Node.js 20+; Git available):

```sh
npx --yes "github:niamatmarjan/brad#v0.4.1" setup
```

BRAD still requires installed native BMAD Method, available host skill invocation, and separate authorization for remote publication. This release does not publish to npmjs.com.
