# BRAD v0.5.2 — Official BMAD setup and Windows reliability

**Release date:** 2026-10-23  
**Status:** Supervised preview. BRAD is a thin router around **project-installed official BMAD workflows**; it is not an autonomous production release agent and is not endorsed by the BMAD Method project.

## What's new

- **Opt-in official BMAD installation:** `brad setup --with-bmad` delegates to the upstream BMAD installer in the selected project when an existing native runtime is not detected. Ordinary `brad setup` still installs only BRAD. An existing runtime is skipped rather than automatically migrated, upgraded, or overwritten.
- **Reliable headless setup:** Noninteractive stable BMAD installation requires explicit `--bmad-modules` and `--bmad-tools`. Incomplete configuration fails without waiting for terminal input. The upstream command has a configurable timeout and process-tree termination on cancellation.
- **Host diagnostics:** Antigravity native skills in `.agent/skills` are recognized as local installation evidence. `doctor` remains read-only and explicitly distinguishes on-disk inventory from actual IDE catalog registration or native skill invocation.
- **Nested npm-exec fix:** BRAD now omits the outer `npm_config_package` selector when launching its nested official BMAD `npx` command. This prevents the official installer from being misidentified as a binary inside BRAD's tarball when BRAD is launched through `npm exec --package`. Other user and npm environment configuration is preserved ([#29](https://github.com/niamatmarjan/brad/issues/29)).
- **Windows file-operation hardening:** Bounded retries address intermittent `EPERM`, `EACCES`, and `EBUSY` errors during installation staging, backup, rollback, and modified-uninstall renames. Nontransient failures still surface; the retry is Windows-only and does not bypass existing protection for user-modified/unmanaged files ([#28](https://github.com/niamatmarjan/brad/issues/28)).

## Installation

Node.js 20+ and Git are required. In the **project where BRAD should be installed**:

```powershell
# Windows PowerShell: install the BRAD skill only
npx.cmd --yes "github:niamatmarjan/brad#v0.5.2" setup --agent antigravity

# Explicit, project-local official BMAD stable setup (BMM and TEA):
npx.cmd --yes "github:niamatmarjan/brad#v0.5.2" setup --agent antigravity --with-bmad --bmad-modules bmm,tea --bmad-tools antigravity --non-interactive

# Read-only local configuration and file-integrity checks:
npx.cmd --yes "github:niamatmarjan/brad#v0.5.2" doctor --agent antigravity --json
```

On macOS/Linux substitute `npx` for `npx.cmd`. Choose `--agent claude`, `codex`, or `copilot` where appropriate. Install or upgrade upstream BMAD **only with project-owner approval**. Live `--with-bmad` installation is intentionally incompatible with `--json`; use `--dry-run --json` to preview safely. The `--bmad-channel preview` v7-alpha path is interactive and has not passed live compatibility acceptance.

BRAD's Node CLI does **not** require Python's `uv` to run. Some installed upstream BMAD Build workflows use `uv` to render instructions; check `uv --version` only when the selected native workflow requires it. Do not silently install global tooling.

## Limitations and safeguards

- v0.5.2 is still a **supervised preview**: review-only tasks must remain read-only; consequential remote writes, PR publishing, merges, deployment, and native-runtime upgrades require the applicable human authorization.
- Some Windows filesystem races may still arise despite bounded rename retries. The owner of the observed temporary Windows file handle was not established. Preserve original errors and report new reproducible failures.
- General host-native Build/TEA capability across every IDE, authenticated Copilot TEA, and BMAD v7-alpha native execution have **not** been universally validated.
- A [public repository history audit](https://github.com/niamatmarjan/brad/issues/16) found no confirmed live secrets in the examined evidence, but historical workstation-path/session metadata remains available in published history. This release does not erase that metadata or certify zero privacy risk.

GitHub Release assets contain the BRAD ZIP, the GitHub-installable npm tarball and `SHA256SUMS.txt`. **Publishing these assets to GitHub does not publish BRAD to npmjs.com.** Verify asset checksums and the tagged commit before using them in automated environments.
