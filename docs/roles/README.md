# Stakeholder guides

**Start with the [ten-role quick reference](quick-reference.md)** for copyable prompts and a consistent evidence-based handoff template. These role guides explain the decisions humans own; they do not imply BRAD simulates ten independent agents. For setup, choose [BMAD v6/v7](../getting-started/choose-bmad-version.md) and the [coding host](../getting-started/host-support.md).

Each guide describes the human responsibility, example BRAD requests, possible native BMAD workflow routing, verification boundaries, and handoffs.

- [Product manager](product-manager.md) · [Business analyst](business-analyst.md) · [Delivery manager](delivery-manager.md)
- [Solution architect](solution-architect.md) · [Technical lead](technical-lead.md)
- [Backend developer](backend-developer.md) · [Frontend developer](frontend-developer.md) · [Full-stack developer](fullstack-developer.md)
- [Functional QA](functional-qa.md) · [Automation QA](automation-qa.md)

**Evidence note:** Many 'Observed evidence' paragraphs describe the historical v0.4.1 Concourse rehearsal, not the current v0.5.2 release. No guide alone certifies that an independent PM, BA, Dev or QA agent was invoked. For more recent host and version test coverage, see the [living compatibility matrix](../reference/compatibility-matrix.md). Continue with [SDLC guidance](../sdlc/README.md).
