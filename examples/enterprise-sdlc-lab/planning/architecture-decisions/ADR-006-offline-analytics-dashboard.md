# ADR-006: Self-Contained Offline Analytics Dashboard Architecture

**Status**: ACCEPTED  
**Date**: 2026-10-24  
**Author**: Marcus Lee (Solution Architect)  

## Context
The mission requires an offline-capable, self-contained analytics dashboard within the example that does not depend on hosted telemetry platforms, external CDNs, or live database connections.

## Decision
We implement a **Static HTML5/SVG Single-File Dashboard**:
- Location: `examples/enterprise-sdlc-lab/analytics/index.html`.
- Consumes JSON generated by `harness/runner/generate_analytics.py` from actual raw test execution events.
- Embeds lightweight responsive SVG charts (confusion matrix, pass-rate breakdown, latency histograms).
- Generates parallel CSV/JSON export files (`results.csv`, `results.json`) for automated CI ingestion.
- Zero external network dependencies (no Google Fonts, no unpinned CDN scripts).
