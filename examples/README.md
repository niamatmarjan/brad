# BRAD examples and demos

## Concourse SDLC lab

[`concourse-sdlc-lab/`](concourse-sdlc-lab/README.md) contains a server-backed local delivery-workflow app, a preserved localStorage prototype, role adoption guidance, current execution evidence, and the offline master report. It is a **partial local rehearsal**, not completion of the planned v0.5.0 85-route / ten-stakeholder validation. Native `bmad-help` skill invocation was verified in a separate project session, but no BMAD product workflow was run. The report distinguishes observed app behavior from fictional seed data and work that remains blocked or unrun; proposed v1.0 quantitative gates are not current results.

This **BRAD v0.4.1 — Concourse SDLC Implementation & Evaluation** example is published for maintainer review under explicit authorization. That authorization does not permit a merge, release, or claim of production readiness. See its [publication review](concourse-sdlc-lab/reports/current/PUBLICATION.md) and follow the [demo publication policy](../docs/evaluation/demo-publication.md).
