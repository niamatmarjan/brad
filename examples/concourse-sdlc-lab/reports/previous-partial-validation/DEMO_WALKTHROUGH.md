# Demo walkthrough

This walkthrough is for the **local product prototype**, not a transcript of the full ten-person SDLC study.

1. Start `app/` with `npm start`, then open `http://127.0.0.1:4173`.
2. Review the Northstar Studio sample workspace and its three projects. Project selection filters the board.
3. Change the demo role in the top bar. Role controls are illustrative client-side checks; they are not a security boundary.
4. Search by title, description or tag, then combine priority, assignee and project filters.
5. Create a work item, open it to edit, or move an assigned item through Ready → In progress → In review → Done. The task detail view includes notes; changes update the team pulse and persist in local browser storage.
6. Switch between board and list views, resize the browser to a phone width, and use keyboard focus to traverse controls.
7. Select **Reset** to restore the fictional seed data.

Seed comments, dates, assignments, task IDs, and activity are demo content. They do not show that any stakeholder actually performed the action.
