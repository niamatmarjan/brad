# Defect Report: DEF-101

**Defect ID:** DEF-101  
**Severity:** MAJOR  
**Reported By:** Chloe Bennett (QA Lead)  
**Assigned To:** Priya Sharma (Dev B)  
**Status:** CLOSED  
**Component:** `server/src/api.mjs` (SLA Evaluation)  
**Date Reported:** 2026-10-20  

### Summary
Input strings with whitespace or invalid ISO date formats for `target_completion_date` caused silent fallback to `NOT_CONFIGURED` or `NaN` rather than validating or evaluating properly.

### Steps to Reproduce
1. Send `POST /api/requests` with `{ target_completion_date: "  2026-10-01T00:00:00Z  " }`.
2. Inspect `sla.status`.
3. Observed: String whitespace caused invalid date parse, returning `NOT_CONFIGURED`.
4. Expected: Whitespace-trimmed date correctly parsed and recognized as `OVERDUE`.

### Fix Resolution
- Trimmed and validated date string before parsing.
- Handled invalid date formats by throwing 400 Bad Request or defaulting cleanly.

### QA Verification
- Regression test `server/tests/defect_101.test.mjs` executed.
- Verified fix passes with trimmed whitespace and past dates.
- Status updated: `OPEN` → `FIXED` → `RETEST_PASSED` → `CLOSED`.
