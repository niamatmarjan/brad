# BRAD v0.5.0 — RelayDesk Enterprise SDLC Example & Evaluation

RelayDesk is a realistic cross-team service request platform evaluating BRAD v0.5.0 across an end-to-end software development lifecycle.

## Overview
- **Application:** Server-backed Node.js 24 (native `node:sqlite`), REST API, role-based authorization, SLA tracking, HMAC webhook dispatcher, and React 19 / Vite 6 browser UI.
- **SDLC Evaluation:** 10 multi-worktree collaboration exercises (ADR, requirements clarification, merge conflict, review rejection, QA defect lifecycle, resumption, and integrated regression).
- **BRAD Auditing:** All 85 canonical routing scenarios evaluated; honest boundary reporting for uninstalled host BMAD.
- **Master Report:** View offline interactive evaluation at `report/MASTER_REPORT.html`.
