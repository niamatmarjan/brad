# BRAD name, branding, and compatibility claims

BRAD's source code is licensed under [MIT](LICENSE). The software license and the public-facing project identity are distinct.

**Clearly allowed:** truthfully saying that your product uses BRAD, identifying compatibility (e.g. "works with BRAD"), linking to this repository, and describing a modified fork as based on BRAD. Preserve MIT notices when required.

**Please avoid:** suggesting an unofficial fork or service is an official BRAD release, implying endorsement by BRAD or BMAD Method maintainers, or using BRAD's project identity for a materially modified distribution in a confusing way. A neutral name such as "My Project (based on BRAD)" helps users distinguish distributions.

No registered-trademark status is claimed by this file, and this guidance does not purport to narrow the MIT copyright license. Rights in names, logos, and trade dress, if any, depend on applicable law. For proposals using the BRAD name prominently, open a branding question through [SUPPORT.md](SUPPORT.md).

**BMAD Method is a separate upstream project.** Do not describe BRAD as officially maintained, certified, or endorsed by the BMAD Method team.
