# Security policy

BRAD can coordinate coding-host tools with filesystem, shell and GitHub access. Treat its skill instructions and any installed third-party workflow as executable operational guidance, and use least privilege.

- **Do not** default to bypassing host permission prompts, auto-merging or deploying.
- Inspect requested external workflows and scripts before permitting privileged execution.
- Keep tokens, private files and environment variables out of issues, logs and eval fixtures.
- When reporting a vulnerability, use GitHub's private security advisory reporting for this repository if available, or contact the maintainer privately through the repository owner profile. Do not post exploit details or secrets in a public issue.

The initial **v0.1.0** release is a supervised preview; production autonomy has not been certified.
