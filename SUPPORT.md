# BRAD support and questions

BRAD is community-maintained preview software; best-effort support is provided through the public GitHub issue tracker when available. There is no guaranteed response-time SLA or paid support implied.

**Before opening a new issue:** run the pinned-version `brad doctor --json`, review [installation](docs/installation.md), [AI setup](docs/AI_SETUP.md), [validation caveats](docs/validation.md), and check existing issues. Include your BRAD/BMAD versions, OS/host, sanitized error, and expected vs. observed behavior. Never include tokens, proprietary source, or private agent transcripts.

- Bugs / regressions → choose **Bug report** from [GitHub Issues](https://github.com/niamatmarjan/brad/issues/new/choose).
- Feature ideas → choose **Feature request** from GitHub Issues; discuss large design changes before implementing.
- Questions → use a regular issue if an appropriate public support channel is enabled; we do not assume GitHub Discussions is available.
- Security vulnerabilities → use the **private** procedure in [SECURITY.md](SECURITY.md).
- Community conduct concerns → see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

BRAD cannot provide privileged access to third-party BMAD services or coding hosts; route problems specific to those tools to their maintainers when confirmed.
